# Security

snap2sheet runs locally and does not upload receipts by default. If you find a security issue, please report it privately.

Email: biniyam.gashaw@hotmail.com

Please do not attach real receipts to a public issue. Use a generated receipt or fake data.

## Scope

Examples of issues worth reporting:

- unsafe file handling in the web upload
- path traversal in output or export paths
- a crash that exposes local file contents
- the optional LLM path sending more than OCR text

Missed fields and wrong totals are accuracy issues. Open a normal issue for those.
